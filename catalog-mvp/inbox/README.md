# Вхідна папка для нових моделей

Поклади сюди сирий GLB з Meshy, і GitHub Actions сам його обробить: оптимізація, постер, запис у каталог. Сирий файл після обробки видаляється.

## Ім'я файлу
- `Бренд__Назва.glb` (два підкреслення між брендом і назвою), наприклад `Nurofen__Pidlogova_vitryna.glb`. Підкреслення в назві стануть пробілами.
- Ідентифікатор береться з латинських літер і цифр імені, тому **називай файл латиницею**.
- Без `__` бренд буде «Інше».

## Необов'язковий файл-супутник
`те-саме-ім'я.json`, наприклад: `{"brand": "Nurofen", "name": "Підлогова вітрина", "yaw": 140}`
- `yaw`: кут огляду постера в градусах. Для Nurofen 140 показує передню сторону; для інших моделей може знадобитися інший (0, 90, 180, 270).
- Щоб змінити кут для вже обробленої моделі, завантаж її GLB ще раз разом із новим json.

## Обмеження
- Через сайт GitHub можна завантажити файл до 25 МіБ. Якщо експорт із текстурою 4K більший, експортуй у Meshy з текстурою 2K.
- Результат треба оглянути: постер у сітці й модель на сторінці каталогу.
- Статус обробки дивись на вкладці Actions репозиторію.
